---
title: Inquiry Payment
description: Query the status of a payment by paymentId or paymentRequestId.
---

`POST /v1/payments/inquiryPayment`

Queries the status of a payment. If both `paymentId` and `paymentRequestId` are provided, `paymentId` takes priority.

## Request Parameters

<ParamField body="paymentId" type="string">
  Wallet-generated unique payment ID.

  **Max length**: 64 characters
</ParamField>

<ParamField body="paymentRequestId" type="string">
  Merchant-generated payment request ID.

  **Max length**: 64 characters
</ParamField>

## Response Parameters

<ResponseField name="result" type="object" required>
  Standard result object with `resultCode`, `resultStatus`, `resultMessage`
</ResponseField>

<ResponseField name="paymentId" type="string">
  Wallet-generated payment ID.

  **Max length**: 64 characters
</ResponseField>

<ResponseField name="paymentRequestId" type="string">
  Merchant-generated payment ID.

  **Max length**: 64 characters
</ResponseField>

<ResponseField name="paymentStatus" type="string">
  Payment status. Values: `SUCCESS`, `FAIL`, `PROCESSING`, `AUTH_SUCCESS`
</ResponseField>

<ResponseField name="paymentTime" type="string">
  Payment completion time in ISO 8601 format.
</ResponseField>

<ResponseField name="paymentAmount" type="object">
  Payment amount. See [Amount](/openapis/v1/data-dictionary#amount).
</ResponseField>
